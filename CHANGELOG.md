# Changelog

## 1.0.0

The first complete local release builds on the original Streamlit prototype.

- React workspace with model selection, progress, source excerpts and saved reports.
- FastAPI jobs with a bounded queue, SQLite history and persistent PDF downloads.
- OpenRouter adapter with explicit configuration, structured output and one repair attempt.
- Bounded page acquisition with robots checks, public-IP validation and verified HTTPS.
- Evidence filters for quotations, keyword gaps and source attribution.
- Evaluation CLI for frozen datasets, multiple models, call limits, latency and usage records.
- Automated backend checks and a production frontend build in GitHub Actions.

This release does not include published live benchmark results or public hosting.
